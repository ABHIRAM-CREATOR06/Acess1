🌐 Web Accessibility Checker v1.0
=====================================

Standalone Windows Application

📋 FEATURES:
- Analyze websites and HTML files for accessibility compliance
- WCAG 2.1, Section 508, and RPwD Act compliance checking
- 6 comprehensive categories: Accessibility, SEO, Performance, Best Practices, Environment, Safety
- Headless browser rendering for JavaScript-heavy sites
- Multiple export formats: TXT, PDF, HTML
- Real-time scoring and compliance assessment
- Environmental impact analysis (energy use, CO₂ emissions)

🚀 HOW TO RUN:
1. Double-click "WebAccessibilityChecker.exe"
2. Enter a website URL or browse for an HTML file
3. Click "Analyze" to start checking
4. View detailed results and scores
5. Export reports using the buttons at the bottom

📊 SCORING SYSTEM:
- 95-100: Fully Compliant
- 80-94: Mostly Compliant
- 60-79: Partially Compliant
- <60: Not Compliant

🔧 SYSTEM REQUIREMENTS:
- Windows 10/11 (64-bit)
- No additional software installation required
- Internet connection for URL analysis

📞 SUPPORT:
This is a standalone application with all dependencies included.
No internet connection required after initial setup.

File size: ~129MB (includes .NET runtime and all libraries)
